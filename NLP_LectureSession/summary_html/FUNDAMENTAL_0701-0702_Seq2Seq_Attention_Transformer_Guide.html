Attention & Transformer

RNN Seq2Seq→ 병목 발견→ Attention→ 행렬화 · QKV→ Transformer

이 가이드는 하나의 질문을 따라간다 — "긴 문장의 정보를 어떻게 잃지 않고 전달할 것인가?" RNN seq2seq의 고정 벡터 병목에서 출발해, attention이 그 병목을 어떻게 뚫었는지, 그리고 Transformer가 어떻게 attention 만으로 시퀀스 변환을 해내는지를 이틀치 강의 흐름 그대로 정리한다.

함께 보기

이 가이드는 "왜 이런 구조인가"를 담당한다. "코드로 어떻게 만드는가"는 이미 완성한 FUNDAMENTAL_day10-13_TransformerWithoutMagic.ipynb가 담당한다 — 각 섹션의 수식이 노트북의 어떤 def에 대응하는지 떠올리며 읽으면 두 자료가 하나로 붙는다.

표기 정리

$h_i$ 인코더 $i$번째 시점의 hidden state
$H$ 인코더 hidden state 전체 $[h_1;\dots;h_T]$
$s_t$ 디코더 $t$번째 시점의 hidden state
$e$ 유사도 점수 (attention score)
$\alpha$ softmax를 거친 attention 가중치
$d_k$ Key(Query) 벡터의 차원 수

01Seq2Seq와 병목

source · 0701 seq2seq_with_attention (전반부)

Seq2Seq는 시퀀스를 입력받아 시퀀스를 생성하는 시퀀스 변환 모델이다. 기계 번역, QA, 요약처럼 "문장이 들어가서 문장이 나오는" 문제가 전부 이 틀에 들어간다. 핵심 설계는 하나 — 입력을 이해하는 인코더와 출력을 생성하는 디코더로 역할을 쪼갠 것이다.

왜 둘로 나누나

① 입력과 출력의 길이가 달라도 대응할 수 있다 (한국어 3어절 → 영어 4단어). ② 이해(NLU)와 생성(NLG)의 역할이 분리되어 각자 최적화할 수 있다. ③ 인코더·디코더를 갈아 끼우기 쉬워 모델 설계가 유연해진다.

RNN으로 구현하면

인코더 RNN이 토큰을 한 개씩 읽으며 hidden state를 갱신하고, 마지막 hidden state를 Context로 삼아 디코더의 초기 상태로 넘긴다. 디코더는 시작 토큰 <s>에서 출발해 "직전에 자신이 뱉은 단어"를 다음 입력으로 받으며 한 단어씩 생성한다 — 이것이 자기회귀(auto-regressive) 생성이다.

RNN seq2seq의 두 가지 한계

① Gradient Vanishing. 시퀀스가 길어질수록 역전파 경로가 길어져 기울기가 소실된다. LSTM·GRU의 게이트 구조로 완화는 했지만 근본 해결은 아니다.

② Long-term Dependency — 정보 소실(Information Vanishing). 이쪽이 더 치명적이다. 입력이 10단어든 100단어든 디코더에게 전달되는 것은 고정 크기 벡터 하나뿐이다. 문장이 길어질수록 앞쪽 단어의 정보는 뒤로 갈수록 덮어써지며 흐려진다. 아무리 좋은 RNN 셀을 써도, "모든 것을 벡터 하나에 압축하라"는 구조 자체가 병목이다.

핵심

문제는 RNN 셀의 성능이 아니라 인터페이스다. 인코더는 매 시점 $h_1, h_2, \dots, h_T$라는 풍부한 정보를 만들어 놓고도, 디코더에게는 마지막 $h_T$ 하나만 건넨다. "버리지 말고 전부 보여주면 안 되나?" — 이 질문이 다음 섹션의 출발점이다.

02Attention의 탄생

source · 0701 seq2seq_with_attention (후반부)

해법은 의외로 단순하다. Context를 한 번 만들어 고정하지 말고, 디코더가 단어를 하나 생성할 때마다 인코더의 모든 hidden state $h_1,\dots,h_T$를 다시 돌아보게 하자. 단, 전부 똑같이 보는 게 아니라 — 지금 생성하려는 단어와 관련 있는 것에 가중치를 실어서 본다. 이렇게 매 시점 새로 합성되는 벡터가 동적 context vector이고, 이 메커니즘이 Attention이다.

검색으로 이해하는 Q · K · V

Attention은 본질적으로 검색이다. 고객센터 문서 검색에 비유하면 세 역할이 선명해진다.

역할정의seq2seq에서의 정체
Query지금 무엇을 찾고 있는가?디코더의 현재 상태 $s_{t-1}$
Key각 단어가 어떤 정보를 갖고 있다고 알리는 색인인코더 hidden state $h_i$
Value각 단어가 실제로 담고 있는 내용인코더 hidden state $h_i$

※ 초기 attention에서는 K와 V가 같은 $h_i$였다. Transformer에서는 여기에 서로 다른 변환($W_K$, $W_V$)을 걸어 색인과 내용을 분리한다 — §03에서 계속.

Attention의 3단계

디코더가 $t$번째 단어를 만들려는 순간, 다음 세 단계가 실행된다.

Attention 레시피

① 유사도 계산 — Q와 각 K의 유사도 점수 $e_i$를 구한다.
② Softmax — 점수를 합이 1인 확률 분포, 즉 가중치 $\alpha_i$로 바꾼다.
③ 가중합 — $\alpha_i$의 비율대로 V를 섞어 새 context vector를 합성한다.

수식으로 — Bahdanau Attention (2014)

최초의 attention은 유사도 함수 자체를 작은 신경망으로 학습했다. 인코더 상태 $H$와 디코더 직전 상태 $s_{t-1}$를 각각 변환해 더하고, $\tanh$를 거쳐 점수로 요약한다.

$$e = W_s \cdot \tanh\!\left(W_{En}H + W_{De}\,s_{t-1}\right)$$ $$\alpha = \mathrm{softmax}(e)$$ $$a=\sum_{i=1}^{T}\alpha_i h_i = H\cdot\alpha$$

세 줄이 정확히 위의 3단계다. 이렇게 만든 context $a$를 디코더의 현재 스텝에 함께 넣어 다음 단어를 예측한다. 병목이 사라졌다 — 디코더는 이제 매 단어마다 입력 문장 전체를 다시 본다.

위젯 01어텐션 실험실 — 내적이 가중치가 되는 순간

주황 화살표 q(디코더 상태)를 드래그해 보자. 각 인코더 벡터 $h_i$와의 내적 → softmax → context 합성이 전부 실시간으로 계산된다. 스텝 버튼은 각 디코딩 시점의 q 위치로 이동시킨다. q와 방향이 비슷한(내적이 큰) 벡터에 가중치가 쏠린다.

디코딩 스텝

점선 주황 벡터가 합성된 context다. q를 두 인코더 벡터의 중간 방향으로 끌면 context도 둘을 섞은 방향이 된다 — attention이 "선택"이 아니라 부드러운 혼합(soft selection)인 이유.

03Scaled Dot-Product Attention

source · 0702 transformer (전반부)

Transformer는 Bahdanau의 "학습되는 유사도 함수"를 버리고 더 과감한 선택을 한다 — 유사도는 그냥 내적으로 잰다. 대신 내적하기 전에 각 벡터를 학습 가능한 행렬 $W_Q, W_K, W_V$로 투영해서, "무엇이 비슷해야 하는지"를 투영 단계가 배우게 한다.

$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V$$

수식 한 줄이지만 §02의 3단계가 그대로 들어 있다. $QK^{\top}$가 모든 Q-K 쌍의 유사도를 행렬곱 한 번으로 계산하고(①), softmax가 각 행을 가중치 분포로 바꾸고(②), $\times V$가 가중합으로 context를 만든다(③). 반복문이 사라지고 전부 행렬곱이 되었기에 GPU 병렬화에 완벽히 올라탄다.

Q, K, V는 어디서 오나

같은 소스라도 서로 다른 학습 행렬을 거쳐 세 역할로 갈라진다. 인코더-디코더 attention(→ §04 Cross)의 경우:

왜 √dₖ로 나누나

내적은 차원 수만큼 곱셈을 더하는 연산이다. Q, K의 각 성분이 평균 0·분산 1이라면 $q\cdot k = \sum_{i=1}^{d_k} q_i k_i$의 분산은 $d_k$가 되어, 점수의 크기가 $\sqrt{d_k}$ 배로 부풀어 오른다. 점수 격차가 커지면 softmax는 포화된다 — 한 곳에 1, 나머지에 0을 주는 원-핫에 가까워지고, 그 지점에서 gradient가 거의 0이 되어 학습이 멈춘다. $\sqrt{d_k}$로 나누면 점수의 표준편차가 차원과 무관하게 ≈1로 유지된다.

위젯 02√dₖ 스케일링 실험 — softmax 포화 관찰

표준정규분포에서 Q, K를 실제 샘플링해 $QK^{\top}$ → softmax를 계산한다. $d_k$를 키우고 스케일링을 꺼 보면 점수 표준편차 σ가 $\sqrt{d_k}$ 배로 커지며 α가 원-핫으로 붕괴(엔트로피 ↓)하는 것을 볼 수 있다.

dₖ
점수 e = QKᵀ / √dₖ
α = softmax(e), 행별

스케일링 없이 dₖ=256이면 평균 max α ≈ 1.0, 엔트로피 ≈ 0 — 사실상 argmax다. softmax가 평평한 영역을 벗어나면 미분값이 소멸해 $W_Q, W_K$가 배울 기회를 잃는다.

Bahdanau vs Scaled Dot-Product

Bahdanau (additive, 2014)Scaled Dot-Product (2017)
유사도$W_s\cdot\tanh(W_{En}H+W_{De}s_{t-1})$ — 작은 신경망이 계산$QK^{\top}/\sqrt{d_k}$ — 순수 내적
학습 대상유사도 함수 자체 ($W_s, W_{En}, W_{De}$)유사도는 고정, 투영 $W_Q, W_K, W_V$가 학습
연산 형태디코더 스텝마다 반복 계산행렬곱 한 번 — 완전 병렬화
위치RNN seq2seq의 보조 장치Transformer의 유일한 정보 혼합 수단

이 수식은 이미 코드로 만들어 본 적이 있다. day10–13 노트북의 그 함수다:

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.shape[-1]
    scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)      # ① 유사도 (÷√dk)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))  # (§04에서)
    weights = softmax(scores, dim=-1)                    # ② attention distribution
    return weights @ V, weights                          # ③ context, α

※ 물론 "without magic" 규칙대로 softmax도 우리가 만든 def다 — F.softmax 아님.

04Attention의 세 가지 얼굴

source · 0702 transformer (중반부)

같은 $\mathrm{softmax}(QK^{\top}/\sqrt{d_k})V$ 하나가, Q·K·V를 어디서 가져오느냐에 따라 세 가지 다른 일을 한다. Transformer 한 층 안에 셋이 모두 들어 있다.

Self-Attention — 문맥이 의미를 바꾼다

같은 단어라도 앞뒤 문맥에 따라 뉘앙스가 달라진다.

같은 "고래", 다른 의미

· 현재도 수많은 고래들이 남획되고 있습니다. — 바다의 생물
· 백경은 고래와 늙은 어부의 사투를 그린 작품입니다. — 소설 속 상징

Word2Vec 같은 정적 임베딩은 두 "고래"에 같은 벡터를 준다. 필요한 것은 문장 안의 다른 단어들을 참조해 자기 표현을 문맥에 맞게 유동적으로 조정하는 장치 — 그것이 self-attention이다. 입력 $X$ 하나에서 $Q=XW_Q,\ K=XW_K,\ V=XW_V$를 모두 만들어, 모든 토큰이 서로를 참조한다.

Cross-Attention — 디코더가 인코더를 본다

디코더가 다음 단어를 추론할 때는 자기 문장만 봐서는 안 되고 인코더의 입력 시퀀스를 참고해야 한다. §02의 seq2seq attention이 Transformer 안에 그대로 이식된 형태다.

Cross-Attention의 출처

Q = 디코더의 hidden state (내가 지금 찾는 것)
K, V = 인코더의 hidden state $H$ (원문이 가진 정보)

번역이라면 "영어 단어를 만들려는 지금, 한국어 원문의 어느 단어를 봐야 하는가"를 매 스텝 계산하는 층이다.

Masked Self-Attention — 병렬 학습과 컨닝 방지

디코더 학습에는 딜레마가 있다. RNN처럼 한 토큰씩 늘려가며 학습하면 순서는 지켜지지만 attention의 병렬 연산 장점이 사라진다. 반대로 정답 시퀀스 전체를 한 번에 입력하면 병렬 학습은 되지만 — self-attention은 모든 토큰을 서로 참조시키므로, "love"를 예측하는 위치가 정답 "love", "an", "apple"을 미리 보게 된다. 실제 추론에서는 다음 토큰을 알 수 없으니, 학습과 추론의 조건이 달라져 버린다(컨닝).

해결책: 전체를 병렬 입력하되, 점수 행렬에서 미래 위치($j>i$)의 점수를 $-\infty$로 덮는다. softmax를 통과하면 $e^{-\infty}=0$이므로 미래 토큰의 가중치가 정확히 0이 된다. 이것이 Look-ahead Mask (Causal Mask)다.

구현은 하삼각 행렬 하나면 끝난다: mask = torch.tril(torch.ones(T, T)) — 0인 자리에 $-\infty$를 채운다.

위젯 03Look-ahead Mask 토글

디코더 입력 <s> I love an의 4×4 self-attention. 각 행이 하나의 시점(Q)이고, 열이 참조 대상(K)이다. 마스크를 꺼 보면 첫 행(<s> 시점)이 미래 정답까지 참조하는 것 — 즉 컨닝 — 이 보인다. softmax는 매번 실제로 재계산된다.

점수 e (마스크 반영)
α = softmax(e), 행별

마스크가 켜지면 각 행의 가중치가 자기 이전(과거+자신)에만 분배된다. 추론 때 디코더가 처한 조건과 정확히 같아지면서도, 모든 행을 한 번의 행렬 연산으로 병렬 학습할 수 있다.

05블록의 나머지 부품

source · 0702 transformer (후반부)

attention이 심장이라면, Transformer 블록에는 심장을 여러 개 병렬로 돌리고(Multi-head), 결과를 비선형으로 가공하고(FFNN), 깊게 쌓아도 무너지지 않게 받치는(Residual + LayerNorm) 부품이 함께 들어간다.

Multi-head Attention — 관계는 하나가 아니다

attention 연산 하나는 한 번에 한 가지 관계만 잡아낸다. 그런데 문장 안에는 주어-동사, 수식어-명사, 대명사-선행사처럼 서로 다른 관계가 동시에 존재한다. 그래서 벡터를 $h$개로 분할해 head마다 독립된 $W_Q, W_K, W_V$로 각각 attention을 수행한다 — 각 head가 서로 다른 subspace에서 서로 다른 관계를 학습한다. 마지막에 concat 후 Linear($W_O$)로 의미를 통합한다.

실제로 head들은 분업한다. 학습된 BERT의 head를 분석한 연구(Clark et al., 2019)에서 확인된 역할 분담:

Head발견된 패턴문법 관계 · 정확도
8-10직접목적어가 자기 동사를 참조dobj · 86.8%
8-11명사 수식어(관사 등)가 명사를 참조det · 94.3%
7-6소유격이 명사구의 head를 참조poss · 80.5%
4-10수동태 조동사가 본동사를 참조auxpass · 82.5%
9-6전치사가 자기 목적어를 참조pobj · 76.3%
5-4상호참조(대명사 ↔ 선행사) 연결coref · 65.1%

Feed-Forward Network — 비선형 가공

"attention 끝에도 Linear($W_O$)가 있는데 왜 또 필요하지?"라는 의문이 들 수 있다. 역할이 다르다. $W_O$의 일은 여러 head가 모은 다양한 문맥 정보를 하나의 표현으로 정리·통합하는 것이고, attention 전체는 결국 V들의 가중 평균(선형 결합)이다. 문맥적으로 중요한 단어를 골라내는 것 이외에, 골라 모은 특징을 비선형으로 조합·변환해 새로운 특징을 만드는 역할이 따로 필요하다 — 그것이 각 토큰 위치에 독립적으로 적용되는 2층 FFNN이다.

$$\mathrm{FFN}(x)=W_2\,f(W_1x+b_1)+b_2$$

원 논문에서 은닉 차원은 $4\times d_{model}$ (512 → 2048), $f$는 ReLU. "attention이 모으고, FFN이 생각한다"고 기억하면 좋다.

Residual Connection — 지름길을 놓는다

Attention이나 FFNN의 출력에 입력 $x$를 그대로 더해준다: $y = F(x) + x$. 층이 배우는 것은 전체 변환이 아니라 변화량(residual) 뿐이라 부담이 줄고, 두 가지가 방지된다 — ① 층을 지나며 원본 정보가 사라지는 정보 손실, ② 역전파가 $+x$ 지름길로 곧장 흐르므로 깊게 쌓아도 gradient vanishing이 완화된다.

Layer Normalization — 스케일 단속

residual은 계속 더하는 구조라, 층을 쌓을수록 출력 스케일이 폭주할 수 있다. LayerNorm은 각 토큰 벡터를 개별적으로 평균 0·분산 1로 정규화한 뒤, 학습 가능한 $\gamma, \beta$로 다시 스케일·이동시켜 값의 범위를 일정하게 유지한다. 학습 속도와 안정성이 올라간다.

$$\mathrm{LN}(x)=\gamma\odot\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta$$
Add & Norm

원 논문의 모든 서브층은 $\mathrm{LayerNorm}(x + \mathrm{Sublayer}(x))$로 감싸진다 — 그림에서 반복되는 "Add & Norm"이 바로 residual(add)과 LayerNorm(norm)의 합작이다. 참고로 배치 단위로 정규화하는 BatchNorm과 달리, LayerNorm은 토큰 하나의 feature 차원에서 정규화하므로 문장 길이·배치 크기에 영향을 받지 않는다.

06전체 아키텍처 — 조립

source · 0702 transformer (Figure 1, Attention Is All You Need)

이제 부품이 전부 모였다. 원 논문의 Figure 1을 재구성한 아래 그림에서 각 블록을 클릭하면 해당 설명 섹션으로 이동한다. 색은 attention의 세 얼굴을 따른다 — Self, Masked Self, Cross.

"love"가 만들어지기까지 — 흐름 따라가기

번역 학습 한 스텝에서 데이터가 지나는 길을 순서대로 밟아 보면:

  1. 인코더 입력 — "나는 사과를 좋아해"가 임베딩되고 Positional Encoding이 더해져 위치 정보를 얻는다.
  2. 인코더 블록 ×N — Self-attention으로 토큰들이 서로 문맥을 교환하고(§04), FFN이 비선형 가공(§05). 매 서브층은 Add & Norm으로 보호된다. 결과가 원문 표현 $H$.
  3. 디코더 입력 — 정답을 오른쪽으로 한 칸 민 <s> I love an이 병렬로 들어간다 (shifted right).
  4. Masked Self-Attention — 각 위치가 과거의 자기 출력들만 참조해 상태를 다듬는다. 미래는 $-\infty$ 마스크로 차단(§04).
  5. Cross-Attention — 디코더 상태가 Q가 되어 인코더의 $H$(K, V)를 검색한다. "love" 자리라면 "좋아해" 쪽에 가중치가 쏠린다(§02·§04).
  6. FFN → Linear → Softmax — 최종 표현이 어휘 크기의 logit으로 투영되고, softmax가 다음 단어의 확률 분포를 내놓는다.
Positional Encoding?

attention은 집합 연산이라 순서를 모른다 — "나는 사과를 좋아해"와 "사과를 나는 좋아해"가 같아져 버린다. 그래서 임베딩에 위치별 고유 패턴(sin·cos)을 더해 순서 정보를 주입한다. 유도와 구현은 day10-13 노트북의 positional_encoding()에서 이미 끝냈으니 여기서는 존재 이유만 기억하면 된다.

한 문장 요약

Transformer는 RNN을 완전히 제거하고, seq2seq의 보조 장치였던 attention을 표현 갱신(self) · 원문 참조(cross) · 병렬 학습(masked) 세 방향으로 확장해 시퀀스 변환의 주역으로 승격시킨 구조다. 그래서 논문 제목이 "Attention Is All You Need"다.

07정리 & 셀프 체크

recap · 0701 + 0702

  1. 병목 — RNN seq2seq는 문장 전체를 고정 벡터 하나에 압축한다. 셀이 아니라 인터페이스가 문제였다.
  2. Attention — 매 디코딩 스텝마다 유사도 → softmax → 가중합으로 동적 context를 합성해 병목을 제거했다.
  3. QKV + 내적 — 유사도를 내적으로 재고 학습은 투영 $W_Q,W_K,W_V$에 맡기면, 전 과정이 행렬곱이 되어 병렬화된다. $\sqrt{d_k}$는 softmax 포화를 막는 안전핀.
  4. 세 가지 얼굴 — 출처만 바꾸면 같은 수식이 self(문맥 반영) · cross(원문 참조) · masked(컨닝 방지 병렬 학습)로 일한다.
  5. 지지 구조 — Multi-head가 관계를 분업하고, FFN이 비선형 가공하며, Residual + LayerNorm이 깊은 스택을 지탱한다.
