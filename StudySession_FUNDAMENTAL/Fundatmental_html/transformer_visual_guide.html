01Seq2Seq, 그리고 병목

Seq2Seq는 시퀀스를 받아 시퀀스를 생성하는 시퀀스 변환 모델입니다 — 기계 번역, QA, 요약이 대표적. 입력을 이해하는 Encoder(NLU)와 출력을 생성하는 Decoder(NLG)로 역할을 분리해, 입·출력 길이가 달라도 대처할 수 있고 모델 설계가 쉬워집니다.

한계 01

Gradient Vanishing

시퀀스가 길어질수록 역전파 과정에서 기울기가 소멸해 앞쪽 토큰까지 학습 신호가 닿지 않습니다.

→ LSTM 게이트로 극복 시도, 근본 해결은 못 함
한계 02

Long-term Dependency

정보가 hidden state를 타고 순차적으로 전달되며 계속 덮어써지므로, 앞쪽 정보가 뒤로 갈수록 희석됩니다 (information vanishing).

→ context vector 하나가 전부를 감당
그리고 결정적으로

순차 연산

t번째 계산은 t−1번째가 끝나야 시작할 수 있어 GPU 병렬화가 막힙니다. 이 문제의식이 곧 Transformer의 출발점.

02Attention — 필요한 곳을, 필요할 때 다시 본다

04Scaled Dot-Product Attention

Bahdanau처럼 점수용 신경망을 따로 두는 대신, Transformer는 내적(dot product)으로 유사도를 잽니다. 행렬곱 한 번이면 모든 Q–K 쌍의 점수가 동시에 나오므로 GPU 병렬화에 완벽하게 들어맞죠.

06세 가지 Attention

Transformer 안에는 같은 수식의 attention이 Q·K·V를 어디서 가져오느냐에 따라 세 가지 모습으로 등장합니다.

6 — A

Self-Attention · 문맥이 의미를 바꾼다

단어는 앞뒤 문맥에 따라 내포하는 뉘앙스가 달라집니다. 그래서 Word2Vec처럼 고정된 벡터가 아니라, 각 토큰이 문장 안의 다른 모든 단어를 참조해 자기 자신의 표현을 문맥에 맞게 조정해야 하죠. 이것이 self-attention이고, Q·K·V가 전부 같은 입력 X에서 나옵니다 — Q=XWQ, K=XWK, V=XWV.

6 — B

Masked Self-Attention · 미래를 가리는 이유

디코더 학습에는 딜레마가 있습니다. 두 소박한 선택지가 모두 실패하거든요.

선택지 A — 실패

RNN처럼 한 토큰씩 늘려가며 학습

순차적 학습은 가능하지만, 시퀀스 전체를 행렬곱 한 번에 처리하는 attention 병렬 연산의 장점이 사라집니다.

선택지 B — 실패

모든 토큰을 그냥 한 번에 입력

학습 단계에서 다음에 올 토큰의 정보를 보고 연산하게 됩니다(치팅). 실제 추론에서는 다음 토큰을 알 수 없으니 학습·추론이 어긋나죠.

해법: 전체를 한 번에 넣어 병렬성은 챙기되, attention score 행렬에서 미래 위치에 −∞를 입력해 softmax 후 가중치가 정확히 0이 되게 만든다 — Look-ahead Mask (Causal Mask). §4 계산기의 "Causal Mask" 토글이 바로 이것입니다.

07블록을 완성하는 부품들

Attention만으로는 블록이 완성되지 않습니다. 깊게, 안정적으로, 순서를 알고 쌓기 위한 네 가지 부품.

FEED-FORWARD NETWORK

토큰별 비선형 변환기

FFN(x) = W2·ReLU(W1x + b1) + b2

Attention에도 linear가 있지만 그 역할은 여러 head의 문맥 정보를 하나의 표현으로 통합하는 것. 문맥적으로 중요한 단어를 골라내는 일 외에, 새로운 특징을 비선형적으로 조합·변환하는 역할이 따로 필요하고 그것이 FFN입니다. 각 토큰 위치에 독립적으로 적용되며(position-wise), 보통 dmodel → 4d → d로 확장했다 줄입니다.

RESIDUAL CONNECTION

F(x) + x — 정보의 지름길

Attention이나 FFN의 출력에 입력 x를 그대로 더해줍니다. 층을 지나도 원본 정보가 사라지지 않고(정보 손실 방지), 미분하면 F′(x)+1이라 기울기가 1의 지름길로 흘러 gradient vanishing을 막습니다. 수십 층을 쌓을 수 있는 비결.

LAYER NORMALIZATION

스케일 폭주 단속반

before — residual 누적으로 폭주
after — 평균 0 · 분산 1

Residual은 입력 값을 계속 더하기 때문에 출력 스케일이 폭주할 수 있습니다. LayerNorm이 각 토큰 벡터의 값을 일정하게 유지해 학습 속도와 안정성을 높입니다. 원 논문은 sublayer 뒤에 적용(Post-LN), 요즘 구현은 대부분 앞에 적용(Pre-LN)합니다.

POSITIONAL ENCODING

순서를 모르는 attention에게 순서를

Attention은 토큰들을 집합처럼 봅니다 — 자리를 바꿔도 결과가 같죠. 그래서 위치마다 고유한 패턴 벡터를 만들어 임베딩에 더해 순서 정보를 주입합니다.

PE(pos, 2i) = sin(pos / 100002i/d)
PE(pos, 2i+1) = cos(pos / 100002i/d)
← 차원 index (주기 짧음 → 김)세로 = 위치 pos ↓

서로 다른 주기의 sin·cos 조합이라 모든 위치가 유일한 무늬를 갖고, 상대 위치 관계가 선형 변환으로 표현되는 좋은 성질이 있습니다.

Q로 K를 조회해서 V를 가중합한다. 이 한 줄이 모델 전체를 관통.

세 가지 얼굴

Self — 문맥 반영 표현 만들기 · Masked Self — 미래 차단하고 병렬 학습 · Cross — 디코더가 인코더를 참조

Multi-Head

head마다 독립 가중치로 서로 다른 subspace의 관계를 병렬 관찰, concat + linear로 통합.

깊게 쌓는 비결

Residual(정보 보존 + gradient 지름길)과 LayerNorm(스케일 단속)이 모든 sublayer를 감싼다.

FFN & PE

FFN은 토큰별 비선형 변환, Positional Encoding은 순서를 모르는 attention에게 위치 정보를 주입.

RNN 대비

어떤 두 토큰도 attention 한 번이면 직접 연결(경로 O(1)), 시퀀스 전체를 행렬곱으로 병렬 학습. 대가는 O(n²) 연산량.
